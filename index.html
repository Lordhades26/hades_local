01 / descripción

¿Qué es HADES-LOCAL?

HADES-LOCAL es un agente de ciberseguridad autónomo que combina herramientas de hacking ético con inteligencia artificial local (Ollama) para realizar auditorías de red, detectar vulnerabilidades y generar reportes profesionales de forma completamente automática. La IA corre 100% en tu máquina.

Reconocimiento
  • Descubre hosts activos
  • Escanea puertos y servicios
  • Mapea superficie de ataque
  • Consultas DNS y WHOIS
Vulnerabilidades
  • Detección de CVEs (nmap)
  • Auditoría web con Nikto
  • Verificación SSL/TLS
  • Scripts de explotación
Análisis IA
  • Nivel de riesgo por host
  • Vectores de ataque
  • Controles ISO 27001
  • Resumen ejecutivo CISO
Reportes
  • Formato Markdown
  • Tabla de riesgos
  • Guardado automático
  • ~/hades_reports/
La IA corre 100% local con Ollama. Sin internet. Sin API keys. Sin límites de uso.

REQUISITOS DEL SISTEMA

Mínimos
  • Python 3.8+
  • RAM: 4 GB
  • Disco: 5 GB
  • Ollama instalado
  • Linux x86_64
Recomendados
  • RAM: 16 GB
  • Disco: 20 GB
  • CPU: 4+ núcleos
  • nmap instalado
  • GPU (opcional)
Pendrive
  • USB 32 GB+
  • Python 3 en host
  • FAT32 o exFAT
  • Sin instalación
  • Cualquier Linux

Instalar HADES-LOCAL

Repositorio público — sin usuario ni contraseña
⌥ github.com/Lordhades26/hades_local ↗
Copia y pega cada bloque en tu terminal Linux. Sin configuración previa. Sin cuenta de GitHub.
PASO 1 — Descargar archivos
bash — pegar en terminal

03 / uso

Comandos del agente

DESDE TERMINAL:

python3 hades_local.py status Estado del agente — modelo IA, herramientas detectadas, PID
python3 hades_local.py tools Lista todas las herramientas de seguridad instaladas por categoría
python3 hades_local.py start Shell interactivo con prompt HADES@sistema ▶
python3 hades_local.py start --auto Modo autónomo — escanea la red cada 30 minutos sin intervención
python3 hades_local.py scan <IP> Escaneo rápido de los 1000 puertos más comunes con análisis IA
python3 hades_local.py recon <red> Reconocimiento completo de una red con análisis de superficie de ataque
python3 hades_local.py fullaudit <red> ⬅ COMANDO ESTRELLA — auditoría automática completa con reporte
python3 hades_local.py audit <IP> Auditoría por controles ISO 27001 de un host específico
python3 hades_local.py analyze <archivo> Análisis forense de .pcap, .hash, binarios con IA
python3 hades_local.py stop Detener el agente si está corriendo en modo autónomo
Los reportes se guardan automáticamente en ~/hades_reports/ en formato Markdown. Desde el pendrive se guardan en pendrive/reports/

DENTRO DEL SHELL INTERACTIVO:

HADES shell
HADES@ubuntu ▶
fullaudit 192.168.1.0/24 # auditoría completa de tu red
scan 192.168.1.1 # escaneo rápido
recon 192.168.1.0/24 # reconocimiento + IA
audit 192.168.1.1 # ISO 27001
analyze captura.pcap # forense de archivo
ask ¿qué riesgo tiene el puerto 554 abierto?
tools # ver herramientas
findings # hallazgos de la sesión
exit # salir

FLUJO DE FULLAUDIT:

FASE 1 — Descubrimiento de hosts activos ▶
Ejecuta nmap -sn sobre el rango CIDR indicado. Detecta todos los dispositivos activos en la red y lista sus IPs. Construye el mapa inicial de objetivos.
FASE 2 — Escaneo completo por host ▶
Por cada host: nmap -sV -sC -p- para identificar todos los puertos abiertos, servicios y versiones. Luego nmap --script vuln para detectar CVEs conocidos.
FASE 3 — Auditoría web y SSL ▶
Para cada servicio HTTP/HTTPS detectado: ejecuta Nikto para encontrar vulnerabilidades web. Verifica certificados SSL/TLS con openssl — detecta vencidos o mal configurados.
FASE 4 — Análisis IA por host ▶
El modelo de lenguaje local analiza todos los hallazgos de cada host. Determina el nivel de riesgo (BAJO/MEDIO/ALTO/CRÍTICO), identifica vectores de ataque probables y proporciona recomendaciones con referencias a controles del Anexo A de ISO 27001.
FASE 5 — Reporte y resumen ejecutivo ▶
Genera un archivo .md con tabla de riesgos por host, hallazgos detallados y resumen ejecutivo para CISO. Guardado automáticamente en ~/hades_reports/

06 / problemas

Solución de problemas

ERROR — Ollama modelo: NO DISPONIBLE ▶

Ollama no está corriendo o no puede conectarse.

ollama serve &
curl http://localhost:11434/api/tags
# En WSL: configura OLLAMA_HOST=0.0.0.0 en Windows
# y actualiza la IP en hades_local.py
ERROR — Herramientas detectadas: 0 o muy pocas ▶
sudo bash scripts/install_tools.sh
python3 hades_local.py tools
ERROR — Timeout durante auditoría ▶

El modelo tardó demasiado. Edita hades_local.py:

OLLAMA_TIMEOUT = 600 # aumenta si tu equipo es lento
ERROR — Pendrive no se monta en WSL ▶
sudo mkdir -p /mnt/e
sudo mount -t drvfs E: /mnt/e
ls /mnt/e/
ERROR — Permission denied en scripts ▶
chmod +x launch.sh hades.sh hades.bin ollama
nmap requiere sudo para algunos escaneos ▶
sudo python3 hades_local.py fullaudit 192.168.1.0/24
